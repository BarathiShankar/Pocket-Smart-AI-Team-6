# Customer Journey Map

{{HEADER:2 Marks}}

| Journey Stage | Stage 1: Discover | Stage 2: Define the Plan | Stage 3: Review & Act | Stage 4: Revisit |
|---|---|---|---|---|
| **Customer Actions** | Opens the application and understands the budget-first concept | Selects a planner, enters budget and requirements, then submits | Reviews allocation, remaining budget and recommended items | Opens history to revisit an earlier plan |
| **Touchpoints** | Landing page and account screens | Home, Party or Jewelry planner | Result panel and external search links | Dashboard and History |
| **Customer Thought** | “Can this reduce the time I spend planning?” | “Will the suggestions respect my limit?” | “I can see where the money is going.” | “I can reuse this plan instead of starting again.” |
| **Customer Feeling** | Curious | Cautiously optimistic | More confident | Reassured |
| **Process Owner** | Sabarirajan R | Sameer Ahamed T + Gogul M | Sameer Ahamed T + Sabarirajan R | Kawin M + Barathi Shankar R |
| **Improvement Opportunity** | Add a short example plan | Add editable budget presets | Add more retailer data and price comparison | Add plan comparison and export |

## Key Journey Principle

The application is designed around one simple transition:

**“I have a spending limit” → “I have a structured plan” → “I can verify the plan before I shop.”**
