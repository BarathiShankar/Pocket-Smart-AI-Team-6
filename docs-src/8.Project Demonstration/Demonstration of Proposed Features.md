# Demonstration of Proposed Features

{{HEADER:1 Mark}}

## Demonstration Checklist

| S.No | Feature | Description | Status | Demonstrated |
|---|---|---|---|---|
| 1 | Account creation and login | Create an account and access protected planning pages | Implemented | Yes |
| 2 | Home budget planning | Generate a fixed-budget home setup plan | Implemented | Yes |
| 3 | Event budget planning | Generate a plan based on guests, event type and selected services | Implemented | Yes |
| 4 | Jewelry planning | Generate occasion-based recommendations with optional outfit image | Implemented | Yes |
| 5 | Budget verification | Recalculate and constrain the final plan | Implemented | Yes |
| 6 | External search links | Continue shopping research from recommendation items | Implemented | Yes |
| 7 | Saved history | Reopen previously generated plans | Implemented | Yes |
| 8 | AI fallback and validation | Continue safely when AI is unavailable or input is invalid | Implemented | Yes |
| 9 | Live retailer price API | Replace search links with live inventory and price data | Future | No |

## Demonstration Message

The key point to demonstrate is not only that the AI can generate recommendations, but that the application **checks the recommendation before accepting it**. This shows the separation between generative output and application rules.
