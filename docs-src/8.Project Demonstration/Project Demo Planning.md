## Demo Flow

1. Explain the problem: users know the budget but not the allocation.
2. Show the landing page and create/sign in to an account.
3. Build one plan and point out category totals and remaining budget.
4. Explain that the server recalculates the total after Gemini responds.
5. Show the history page and reopen the generated plan.
6. Demonstrate one validation case.
7. Finish with current limitations and future improvements.

## Pre-Demo Checklist

- Install dependencies and confirm the application starts.
- Configure the Gemini API key if a live AI demonstration is required.
- Keep a small JPG/PNG/WEBP outfit image ready for the jewelry demonstration.
- Confirm that the database is writable.
- Run the functional tests before the final rehearsal.
- Verify that the GitHub repository and phase PDFs contain the final team names.
